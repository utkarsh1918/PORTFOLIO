📋 Project Overview

This project focused on identifying, simulating, and analyzing Distributed Denial-of-Service (DDoS) attacks using traffic capture and detection methods. It includes packet sniffing, protocol-based filtering, traffic anomaly visualization, and response strategies using IDS/IPS systems.

🧰 Tools & Techniques Used

Wireshark Snort IDS Python Scapy TCPDump LOIC (Simulated) Traffic Analysis Packet Filtering

🔍 Key Insights

  • Detection of SYN Flood patterns in network packets.
  • Utilization of real-time packet inspection via Snort IDS rules.
  • Simulation of DDoS traffic using controlled LOIC tools in isolated networks.
  • Custom Python scripts using Scapy to analyze packet behaviors and frequency.

🧠 Learning Outcomes

Through this project, I deepened my understanding of network protocols, real-time detection mechanisms, and cyber-attack response strategies. It provided hands-on experience with both attack simulation and mitigation techniques, enhancing my capability to architect secure systems.
