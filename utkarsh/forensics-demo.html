🧩 Digital Forensics Report

Incident Response | Evidence Analysis | Case Reconstruction

📋 Project Overview

The Digital Forensics Report project simulates a post-incident cyber investigation involving a compromised system. Using forensic tools like FTK Imager and Autopsy, we performed a detailed analysis of disk images, registry files, hidden artifacts, and user activity logs. The goal was to uncover digital evidence, understand the breach timeline, and maintain the integrity of data throughout the investigation.

🧪 Investigation Workflow

The forensic process followed these core phases:

  • Imaging: Acquired a bit-by-bit copy of the compromised system's drive using FTK Imager.
  • Initial Triage: Conducted basic checks for suspicious file signatures and timestamps.
  • Timeline Analysis: Used Autopsy to reconstruct chronological events including file access, deletions, and user logins.
  • Keyword Search: Searched for known malware strings and confidential document names.
  • Registry Parsing: Extracted USB history, user shellbags, and program execution records.

🧰 Tools & Techniques Used

FTK Imager Autopsy Disk Imaging Timeline Analysis Registry Forensics Metadata Extraction Steganography Detection Report Documentation

📌 Key Findings & Outcomes

  • Identified unauthorized access through an unpatched RDP vulnerability.
  • Discovered obfuscated files embedded with steganography tools.
  • Reconstructed complete attacker timeline from login to data exfiltration.
  • Maintained complete chain of custody logs and documented findings professionally.

⚠️ Challenges & Mitigations

  • Encrypted Files: Certain files were encrypted—utilized entropy analysis and known-plaintext attacks for clues.
  • Timestamp Manipulation: Detected time-stomping using MAC timestamp correlation techniques.
  • Data Volume: Managed large volumes using filtering and indexing capabilities of Autopsy.
