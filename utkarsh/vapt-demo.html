Vulnerability Analysis | Exploitation Simulation | Security Hardening

📋 Project Overview

This VAPT (Vulnerability Assessment & Penetration Testing) project focused on identifying, exploiting, and reporting security flaws in a simulated enterprise-grade web application. The goal was to test the system's resistance against real-world attack vectors using both manual techniques and automated tools. All findings were documented in a professional penetration test report with severity ratings and recommended mitigations.

⚙️ Assessment Methodology

  • Reconnaissance: Network and application scanning using Nmap & WhatWeb.
  • Vulnerability Scanning: Automated scanning using OWASP ZAP & Nikto.
  • Manual Exploitation: Performed manual SQL Injection, XSS, and IDOR testing using Burp Suite.
  • Post-Exploitation: Used Metasploit to simulate remote shell access & privilege escalation.
  • Reporting: Documented vulnerabilities with screenshots, CVSS scores, and patch recommendations.

🧰 Tools & Techniques Used

Burp Suite OWASP ZAP Metasploit Framework Nmap Kali Linux SQL Injection XSS Testing Directory Bruteforce CVSS Scoring IDOR Exploitation

🚨 Key Vulnerabilities Discovered

  • SQL Injection: Critical vulnerability in login endpoint allowed full DB dump.
  • Reflected XSS: Found on multiple GET parameters, vulnerable to cookie theft & redirection attacks.
  • IDOR (Insecure Direct Object Reference): Unauthenticated access to user profiles via predictable IDs.
  • Directory Listing Enabled: Web server disclosed file structure due to misconfiguration.

📊 Risk Matrix & Recommendations

  • High: SQLi → Use parameterized queries, implement WAF rules.
  • Medium: IDOR → Enforce session-based access controls.
  • Medium: XSS → Apply output encoding, CSP headers.
  • Low: Directory Listing → Disable in server config, use `.htaccess` rules.
